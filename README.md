
Archana's Ice Cream Parlour is a visually appealing, pastel-themed website developed to represent an ice cream business. The website features a clean, attractive design and a user-friendly interface, providing visitors with a pleasant browsing experience.

Users can explore the available offerings, select their location, and contact the parlour to place orders through the Contact Us page.

Technologies Used

- HTML5 – For structuring the website content.
- CSS3 – For styling, layout, and visual design.

Project Objective

This project was developed as a web development practice project to strengthen fundamental skills in HTML and CSS while creating an attractive and responsive user interface.
